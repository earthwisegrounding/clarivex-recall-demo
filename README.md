# Clarivex Recall — a scam-awareness demonstration

**This is not a real product.** "Clarivex Recall" does not exist, and nothing can be bought on this page.

The page imitates the style of online ads that promise to restore memory with a pill. It was built to show a family member how quickly and cheaply that kind of marketing can be faked.

- Pressing either order button shows a "this website is fake" message instead of a checkout. The page collects no information of any kind.
- The "Is this real?" button in the bottom-right corner outlines every invented element (the countdown timer, the doctor, the news outlets, the statistics, the reviews, the price, the stock counter, the badges) and explains how each one was faked.
- Every name, quote, number and outlet on the page is invented. Any resemblance to a real product, company or person is coincidental.

No pill, vitamin or supplement has been shown to cure or reverse Alzheimer's disease or dementia. Talk to a doctor before buying anything for memory. In the US, suspicious health ads can be reported at https://reportfraud.ftc.gov.
